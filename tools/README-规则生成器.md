# TXCS 规则生成器 使用说明

位置：`D:\Whale\chrome_url_interceptor\tools\txcs-rule-generator.html`
单文件工具，双击用浏览器打开即可，无需安装、无需联网、零依赖。

## 它是干什么的

把"每月手动写脚本生成拦截规则"变成页面点几下：
导入现有规则文件 → 自动识别模板组（同接口、只差月份的规则）→ 勾选新月份 → 一键生成 → 导出新规则文件。

## 典型使用流程（每月更新一次）

1. 双击打开 txcs-rule-generator.html
2. 点右上角「⬆ 导入规则文件」，选 rules 目录里最新的文件
   （如 `海盛和食品_20260810_01.json`，命名约定：`{店铺}_{YYYYMMDD}_{序号}`）
   左侧会自动按平台分类，并识别出可批量生成的模板组（如"京麦新版 getSummary 已生成至 2026年8月"）
3. 点某个模板组 → 右侧出现生成面板
4. 点选目标月份（如 2026年9月，可多选）→ 若有"指标速填"框（京麦新版接口），填新月份的
   8 个指标（PV/UV/成交用户/成交率/成交单量/成交商品数/成交金额/件单价），
   不填则沿用基底月份数值
5. 点「⚡ 生成选中月份规则」→ 新规则以绿色高亮出现在下方表格
6. 重复第 3~5 步处理其他平台（猫超/生意参谋/微信小店/电子税务局），或直接在左侧"全部"里看
7. 点「⬇ 导出规则文件」→ 得到 `{店铺}_{YYYYMMDD}_{序号}.json`（同一天多次导出序号递增 01/02/03），
   放进扩展的 rules/ 目录（2026-08-10 起文件命名统一此格式）
8. 扩展 popup → Import 导入（注意：**导入前先把扩展里旧规则清空**，见下）

## 重要注意事项

- **扩展导入是"按 URL pattern 去重合并"**：同一接口不同月份的规则 pattern 相同，
  直接导入新文件会跳过 pattern 已存在的规则。正确做法：
  扩展 popup 里逐个删掉旧规则（或重装扩展）后，再 Import 完整新文件。
  工具导出的文件是"基底规则 + 新生成规则"的完整集合，一次导入即最新全量。
- **编辑规则 = 表单操作，不用手写 JSON**：点任意规则的 ✏️ 按钮，弹窗默认是「📝 表单编辑」——
  响应里的数字字段自动变成中文表单（微信小店直接读页面自带的中文标签：成交金额/成交订单数/成交人数…；
  其他平台按字段名自动翻译），填好数字点保存即可，类型（数字/字符串）自动保持。
- **新增一条微信小店数据（举例）**：导入文件 → 点左侧"微信小店"模板组 → 生成面板勾选新月份
  （如 2026年9月）→ 生成 → 点绿色高亮行 ✏️ → 表单里填新月份的成交金额/订单数等 →
  点「🔄 计算环比」自动按上月规则算好环比 → 保存 → 导出。
- **环比/同比自动处理**：生成新月份规则时 *_tb/_ind（环比/同比）自动清空；
  填完本月数值后点「🔄 计算环比」，工具自动找同接口上月规则计算所有环比。
  （同比 *_ind 需要去年同期数据，工具不自动算，可留空或手填。）
- **JSON 编辑仍可用**：弹窗切「{} JSON 编辑」可看/改完整原始 JSON（含 metaConfig、趋势数组等表单不展示的部分）。
- **生成后建议编辑数值**：除京麦新版外，其他平台（猫超/生意参谋/微信小店/税务）的新月份规则
  默认复制基底数值，生成后点绿色高亮行的 ✏️ 用表单改关键数字。
- **趋势数据是"平移"**：getTrend 等每日序列会按基底月份分布形态搬到新月份
  （天数不同时裁剪/补 0），配合京麦新版"指标速填"会自动按新总量缩放。
- **工具数据自动保存在浏览器 localStorage**：关页面不丢；「清空」按钮可重置。

## 日期替换规则（生成时自动处理）

- alias / bodyPattern / URL / 响应中的日期全部联动到新月份
- startDate、endDate、stat_date（月末）→ 新月
- compareStartDate、compareEndDate 及早于基底月的日期值（如猫超 olap 的 value 行）→ 环比上月
- 4 位数字 code（1757 等）不会被误替换
- 响应结构（JSON 键）保持不变，只动日期和（速填时的）数值
